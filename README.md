# ClipSlim Desktop

Fast, private video compression for Windows. Everything runs on your PC; nothing is uploaded.

**Download:** grab `ClipSlim-Desktop-Setup-<version>.exe` from the [latest release](https://github.com/Styphler17/clipslim-desktop/releases/latest).
Installed copies update themselves automatically.

Free to use. ClipSlim Pro (lifetime licence) unlocks 2 files at once, H.265/VP9, .mkv/.webm, watch folders and saved presets.

This repository only hosts installers and update files.
